# Contribution Guidelines

Thank you for your interest in contributing to the Digital Reputation & OSINT Tools Curator!

## How to Contribute

### Suggesting a New Tool
1.  **Open an Issue:** Use the Issues tab to suggest a new tool.
2.  **Provide Details:** Include:
    - Tool name
    - URL
    - Brief description of its purpose
    - Which category it belongs in
    - Why it's valuable for digital reputation work

### Adding a Tool via Pull Request
1.  Fork this repository
2.  Add your tool to the appropriate section in `README.md`
3.  Follow the existing format precisely
4.  Submit a pull request with a clear description of your addition

## Guidelines
- Tools must be relevant to OSINT, digital reputation, or online risk assessment
- Commercial tools are acceptable but must be clearly indicated
- All suggestions are reviewed for relevance and quality

## Questions?
Open an issue with your questions and we'll respond promptly.
