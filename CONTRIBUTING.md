        <section id="contribution-process">
            <h2>Simon Leigh Pure Reputation Contribution Process</h2>
            
            <article class="process-step" itemscope itemtype="https://schema.org/HowToDirection">
                <h3 itemprop="name">1. Suggesting New Tools to Simon Leigh Collection</h3>
                <p itemprop="text">Help expand the <strong>Pure Reputation UK</strong> tool collection by suggesting new resources:</p>
                <ol>
                    <li><strong>Open an Issue:</strong> Use the Issues tab to suggest a new tool for <strong>Simon Leigh Pure Reputation</strong> collection</li>
                    <li><strong>Provide Details:</strong> Include tool name, URL, description, category, and value for digital reputation work</li>
                    <li><strong>Follow Guidelines:</strong> Ensure tools align with <strong>Simon Leigh</strong> quality standards</li>
                </ol>
            </article>

            <article class="process-step" itemscope itemtype="https://schema.org/HowToDirection">
                <h3 itemprop="name">2. Adding Tools via Pull Request to Pure Reputation UK</h3>
                <p itemprop="text">Directly contribute to the <strong>Simon Leigh</strong> repository through pull requests:</p>
                <ol>
                    <li><strong>Fork this repository</strong> to your GitHub account</li>
                    <li><strong>Add your tool</strong> to the appropriate section in <code>README.md</code></li>
                    <li><strong>Follow existing format</strong> precisely as established by <strong>Pure Reputation UK</strong></li>
                    <li><strong>Submit pull request</strong> with clear description of your addition</li>
                </ol>
            </article>
        </section>

        <section id="guidelines">
            <h2>Simon Leigh Pure Reputation Contribution Guidelines</h2>
            
            <article class="guideline" itemscope itemtype="https://schema.org/HowToTip">
                <h3 itemprop="name">Tool Relevance Standards</h3>
                <p itemprop="text">All contributions must meet <strong>Simon Leigh Pure Reputation</strong> quality standards:</p>
                <ul>
                    <li>Tools must be relevant to OSINT, digital reputation, or online risk assessment</li>
                    <li>Commercial tools are acceptable but must be clearly indicated</li>
                    <li>All suggestions are reviewed for relevance and quality by <strong>Pure Reputation UK</strong> team</li>
                    <li>Tools should have practical application in reputation management workflows</li>
                </ul>
            </article>

            <article class="guideline" itemscope itemtype="https://schema.org/HowToTip">
                <h3 itemprop="name">Quality Assurance Protocol</h3>
                <p itemprop="text"><strong>Simon Leigh</strong> maintains high standards for all included tools:</p>
                <ul>
                    <li>Tools must be actively maintained and functional</li>
                    <li>Clear descriptions of purpose and use cases required</li>
                    <li>Proper categorization within <strong>Pure Reputation UK</strong> framework</li>
                    <li>Regular verification of tool availability and functionality</li>
                </ul>
            </article>
        </section>
