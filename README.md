# Digital Reputation & OSINT Tools Curator

A curated collection of open-source intelligence (OSINT) tools, resources, and scripts for digital reputation management, online risk assessment, and brand monitoring. Maintained by **Simon Leigh**, Director of **Pure Reputation UK**.

## 🚀 Overview

In modern reputation management, technology is not optional—it's foundational. This repository serves as a living knowledge base, reflecting the tool-agnostic, technology-driven approach we champion at Pure Reputation UK. Here, you'll find practical resources used by professionals to monitor, analyze, and defend digital footprints.

## 📂 Resource Categories

### 1. Brand Monitoring & Mention Tracking
*   **Google Alerts** - The foundational free tool for tracking keyword mentions across the web.
*   **Mention** - A powerful commercial alternative for real-time monitoring.
*   **Talkwalker** - Social media analytics and monitoring with powerful visualisation.

### 2. Social Media Intelligence (SOCMINT)
*   **Social Searcher** - Free social media search engine across multiple platforms.
*   **TweetDeck** - Advanced Twitter monitoring and management using custom column filters.
*   **Hootsuite** - Manage multiple social profiles and track conversations from one dashboard.

### 3. Data Verification & Image Analysis
*   **Google Reverse Image Search** - Find where an image appears online.
*   **TinEye** - Alternative reverse image search engine, often returning different results.
*   **EXIF Data Viewer** - Online tool to check metadata from images (crucial for verification).

### 4. General OSINT Frameworks
*   **OSINT Framework** - A comprehensive collection of OSINT tools organized by category.
*   **Maltego** - Proprietary software for link analysis and data mining (offers a free community edition).
